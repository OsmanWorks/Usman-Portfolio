About This Project

Results come from live map data, not a manual list.

Data Sources

  • OpenStreetMap Overpass API for places (clinics, shops, mechanics and more), free and keyless.
  • OpenStreetMap Nominatim to turn a typed city into coordinates.
  • CARTO for base map tiles.

Limitations

  • Coverage depends on how well an area is mapped on OpenStreetMap.
  • Phone numbers only show when they have been added by contributors.
  • Public map servers can be slow at times. The app retries other mirrors automatically.
