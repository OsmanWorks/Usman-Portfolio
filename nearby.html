About this project

Type a need and a place, anywhere in the world, and this tool automatically searches live map data — no manually entered listings.

Data sources

  • OpenStreetMap Overpass API — live, community-mapped places (clinics, shops, mechanics, etc.), free and keyless.
  • OpenStreetMap Nominatim — turns a typed city or address into coordinates.
  • CARTO — base map tiles.

Known limitations

  • Coverage depends on how thoroughly a given area has been mapped on OpenStreetMap — dense in many cities, sparser in some towns.
  • Phone numbers and hours only show when contributors have added them.
  • Public Overpass servers can be slow at peak times; the app retries a couple of mirrors automatically.
